# OpenClaw Hebrew for Windows

ערכת התקנה ושדרוג לגרסת OpenClaw Windows Hub בעברית מלאה, כולל תמיכה כללית ב־RTL.

הערכה משדרגת את ההתקנה הרגילה הקיימת. אין להסיר קודם את האפליקציה האנגלית. לפני ההתקנה נוצר גיבוי של ההגדרות, חיבורי ה־Gateway ונתוני המשתמש.

## התקנה ללא ZIP

פתח PowerShell והריץ:

```powershell
git clone https://github.com/huxhkuh/ASASASAS.git OpenClaw-Hebrew
cd OpenClaw-Hebrew
powershell -ExecutionPolicy Bypass -File .\START.ps1
```

`START.ps1` מוריד את גרסת המקור המדויקת של OpenClaw, מחיל את שינויי העברית, מריץ את הבנייה ואת כל הבדיקות הנדרשות, יוצר מתקין Release עבור win-x64 ומתקין אותו כשדרוג מעל האפליקציה הקיימת.

אם Git אינו מותקן, אפשר לפתוח את המאגר ב־GitHub Desktop ולשכפל אותו למחשב. לאחר מכן יש להריץ את `START.ps1` מתוך התיקייה המקומית.

## מה כלול

- 2,888 מחרוזות מתורגמות, בהתאמה מלאה לקובץ `en-us`.
- תמיכה גנרית ב־RTL לפי תרבות הממשק.
- שמירת URL, token, IDs, פקודות, נתיבים וערכים טכניים בכיוון LTR.
- כיסוי onboarding, Settings, תפריטי tray, דיאלוגים, התראות ומשטחי Windows המקוריים של האפליקציה.
- גיבוי אוטומטי לפני החלפת ההתקנה הקיימת.

## במקרה של שגיאה

אין להסיר את OpenClaw. יש להעתיק את כל הפלט מחלון PowerShell ולשלוח אותו לבדיקה. האפליקציה המותקנת אינה משתנה לפני שהבנייה, הבדיקות ויצירת המתקין הסתיימו בהצלחה.
